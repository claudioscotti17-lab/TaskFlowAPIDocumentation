# Welcome to TaskFlow

TaskFlow is a REST API designed to help developers organize projects and manage tasks through a straightforward, project-based workflow.

With TaskFlow, you can create projects, add tasks to existing projects, retrieve project tasks, update task statuses, and delete tasks when they are no longer needed.

## How TaskFlow works

TaskFlow uses a project-based data model. Each task belongs to a project and is identified by a unique task ID.

A typical workflow follows these steps:

<Steps>
  <Step title="Create a project">
    Send a `POST /projects` request to create a project and obtain its `project_id`.
  </Step>
  <Step title="Create a task">
    Send a `POST /tasks` request using the existing `project_id`.
  </Step>
  <Step title="Retrieve project tasks">
    Use `GET /projects/{project_id}/tasks` to list tasks belonging to a project.
  </Step>
  <Step title="Update task progress">
    Use `PATCH /tasks/{task_id}` to change a task's status.
  </Step>
  <Step title="Delete a task">
    Use `DELETE /tasks/{task_id}` to remove a task.
  </Step>
</Steps>

## Task statuses

Tasks use one of three supported status values:

| Status | Description |
| --- | --- |
| `pending` | The task has been created and work has not started. |
| `in_progress` | Work on the task is underway. |
| `done` | Work on the task has been completed. |

Newly created tasks start with the `pending` status.

<Note>
  A project must exist before you can create tasks within it. Requests that reference a nonexistent project return a `404 Not Found` response.
</Note>
